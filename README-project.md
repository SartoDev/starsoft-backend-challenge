# 🚀 Desafio Backend Starsoft

Sistema de venda de bilheteria de cinema desenvolvido em **NestJS**, utilizando:

- **Kafka**
- **Redis**
- **PostgreSQL**
- **Prisma**
- **Docker**
- **Swagger**

---

## ✅ Pré-requisitos

Antes de rodar o projeto, você precisa ter instalado:

- [Docker](https://www.docker.com/)

---

## ⚙️ Configuração do ambiente

Crie o arquivo `.env` na raiz do projeto (siga de exemplo o `.env-example`)

Depois disso, ajuste os valores no `.env` caso necessário.

---

## 🐳 Rodando o projeto com Docker

Com o Docker instalado e o `.env` criado, rode o comando:

```bash
docker compose up
```


---

## 🧪 Acessando a aplicação

Após subir tudo, a API ficará disponível em:

```
http://localhost:3000/api
```

---

## 📦 Acesse a documentação do Swagger

Esse projeto possui uma documentação desenvolvida com Swagger, ela ficará disponível em:

```bash
http://localhost:3000/api-docs
```

---

## 🧹 Parando os containers

Para parar os containers:

```bash
docker compose down
```
